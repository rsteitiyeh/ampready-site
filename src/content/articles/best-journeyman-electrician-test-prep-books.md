For most journeyman candidates, the strongest single pairing is a code-based study guide (Mike Holt's or Ray Holder's) plus a pocket field reference (Ugly's Electrical References) for the calculation tables you'll use in every practice problem. No single book covers both memorization and calculation practice equally well.

Journeyman exams test two different skills: recalling NEC rules and applying them under a clock to load calculations, conductor sizing, and clearance questions. A study guide builds the first skill through explanation and practice questions; a pocket reference builds calculation speed by putting the tables you need in one place instead of a full code book.

## What's actually in Mike Holt's journeyman exam prep package?

Mike Holt's journeyman exam preparation materials, published to track the current NEC cycle, include hundreds of full-color instructional graphics and, per [Mike Holt Enterprises' own product listing](https://www.mikeholt.com/examprep-journeyman.php), over 2,100 practice questions across the package. The graphics-heavy format is built for visual learners working through code articles they haven't fully memorized yet, and the volume of practice questions gives enough repetition to expose weak spots before exam day. The tradeoff is cost: full coverage usually means buying more than one book in the series rather than a single title.

## How does Ray Holder's guide compare?

Ray Holder's "2026 Journeyman Electrician Exam Prep and Study Guide" packages 400-plus practice questions with study material in a single volume, according to its [Amazon listing](https://www.amazon.com/2026-Journeyman-Electrician-Study-Guide/dp/B0G1XQBN5G). Holder is a master electrician and instructor with decades in the trade, and his guides run noticeably cheaper than Mike Holt's multi-book series. The consistent trade-off mentioned across user reviews of Holder's line: fewer illustrations and occasional errors in worked calculations, so cross-check any calculation example against the code book itself rather than trusting the arithmetic blind.

## Is Ugly's Electrical References worth buying alongside a study guide?

Yes, and it's the cheapest of the three at $28.95 for the current spiral-bound edition, per the [publisher's listing](https://www.uglys.net/ugly-s-electrical-references-2026-edition). It's not a study guide. It's a pocket-sized table reference: ampacity charts, conduit fill, box fill, NEMA configurations, and conversion tables, the exact data a candidate looks up dozens of times while working practice problems. Most working electricians already own a copy for the field; the same copy doubles as an exam-study tool since it's small enough to keep open next to whatever prep book you're actually studying from.

## Do you need the actual NEC code book, or is a study guide enough?

You need the code book itself at some point, because study guides summarize and interpret the NEC, they don't replace it, and several state exams (California's DIR General Electrician exam among them) are open-book with the NEC provided at the test center. Studying exclusively from a third-party guide without ever opening the actual code, published by [NFPA as NFPA 70](https://www.nfpa.org/product/nfpa-70-code/p0070code), leaves you slower at navigating the real document on exam day, which matters when the test is timed.

## FAQ

**Is one book enough to pass the journeyman exam?**
Rarely. Most candidates who pass on the first try combine a study guide for concepts and practice questions with a pocket reference like Ugly's for fast table lookups, plus timed practice tests closer to exam day.

**Do I need the newest NEC edition, or can I study from an older one?**
Study from whatever edition your state currently has adopted for testing, not necessarily the newest published edition. States adopt NEC cycles on their own schedule, so check your state board's candidate handbook before buying a code book or guide tied to a specific year.

**Are free PDF versions of these study guides reliable?**
Treat unofficial free PDFs with caution. Beyond the copyright issue, pirated copies are frequently outdated editions circulating years after a new code cycle, which teaches wrong answers on anything that changed.

**What's the difference between a study guide and a practice test book?**
A study guide explains the code with worked examples built around teaching the concept. A dedicated practice test book is mostly just questions and answer keys, useful once you already understand the material and want timed repetition.
