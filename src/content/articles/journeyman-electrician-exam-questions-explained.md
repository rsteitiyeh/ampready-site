Journeyman electrician exam questions fall into five recurring types: direct code lookups, calculations, scenario/application questions, definitions, and "which article applies" questions that test whether you know where a topic lives in the NEC before you can even start answering it. Every state exam mixes these differently, but the categories themselves are consistent nationwide because they all draw from the same code book.

Knowing the type of question you're looking at before you start solving it saves time. A calculation question wastes your time if you try to answer it from memory instead of pulling the table. A definitions question wastes your time if you go hunting through an article when the answer is sitting in Article 100.

## Direct code-lookup questions

These ask you to find a specific requirement and apply it. "What is the minimum working clearance in front of a 240V panelboard under Condition 2 spacing?" is a lookup question. You don't need to reason it out, you need to find NEC Table 110.26(A)(1) fast. Speed on this question type comes entirely from how well you've tabbed your code book, not from how well you understand electrical theory.

## Calculation questions

These require you to compute something: box fill, conductor ampacity with derating, service load calculations, voltage drop, or motor overload sizing. They usually give you a scenario with specific numbers (conductor count, box dimensions, load in amps) and ask for a result, not a code citation. On most state exams, calculation questions are the slowest per-question because you're doing math on top of a table lookup, not instead of one.

## Scenario or application questions

These describe a real installation situation and ask what code requires. "A kitchen countertop receptacle in a dwelling unit is on a dedicated 20A circuit. What protection does it require?" is an application question: it tests whether you can connect a real-world description ("kitchen countertop receptacle, dwelling unit") to the correct code section (GFCI under 210.8(A), AFCI under 210.12(A) in most current cycles) without the question spelling out the article number for you.

## Definitions questions

These test precise NEC terminology, and they're graded strictly. "Readily accessible" and "accessible" are both defined terms in Article 100 with different meanings; a question that hinges on that distinction is testing whether you know the code's specific vocabulary, not whether you understand electrical work generally. These questions are usually fast to answer once you've studied Article 100 directly, since the wording rarely leaves room for interpretation.

## "Which article applies" questions

These are the trickiest for people who know the material but haven't practiced under time pressure. The question gives you a situation and multiple plausible-sounding article citations as answer choices, and you have to identify which one actually governs. A common distractor pattern: pairing NEC 250.66 (grounding electrode conductor sizing, based on the largest ungrounded service conductor) against 250.122 (equipment grounding conductor sizing, based on the overcurrent device rating) as answer choices for the same question. Exam writers know these two get confused constantly.

## A quick reference table

| Question type | What it's really testing | Fastest way to prepare |
|---|---|---|
| Code lookup | Tab speed and index familiarity | Timed drills finding specific articles cold |
| Calculation | Math accuracy under a clock | Repeat problem sets until the steps are automatic |
| Scenario/application | Connecting real situations to the right code section | Practice questions with realistic field scenarios, not just bare code text |
| Definitions | Precise terminology from Article 100 | Flashcard the terms with a specific code meaning |
| Which article applies | Distinguishing similar-sounding but different rules | Drill known mix-up pairs (250.66 vs 250.122) specifically |

## How distractors are built

Wrong answers on a well-built exam aren't random. They're usually one of: the right number from the wrong table, the right article with the wrong subsection, a rule that applies to a similar but different situation (commercial vs dwelling unit requirements are a classic swap), or an outdated rule from a prior code edition. When you're stuck between two answers, ask which one applies to a slightly different situation than the one described. That's often the distractor.

## State format differences that change the question mix

The five question types above are consistent everywhere, but how many of each type you'll see depends on your state. Texas now runs a dedicated 26-question Calculations portion separate from its 59-question NEC Knowledge portion, so you know in advance which clock you're on for which question type ([TDLR Electrician Exam Information](https://www.tdlr.texas.gov/electricians/elecexam.htm)). States that run a single combined exam mix calculation and lookup questions together, so you have to switch modes mid-test without a clean break.

## FAQ

**Are journeyman electrician exam questions multiple choice?**
Yes, in every state we're aware of. You choose from four answer options per question, computer-delivered at PSI or a similar testing vendor.

**How many calculation questions are on the exam?**
It varies by state. Texas's Calculations portion alone runs 26 questions; states with a single combined exam typically weight calculations at roughly a third of the total question count based on published content outlines, though the exact split is set by each state board.

**Do exam questions ever reference a specific NEC edition by year?**
Not usually in the question text itself, but the correct answer depends on which edition the exam is referenced to. Texas currently references the 2023 NEC even though the 2026 NEC has been published, so always confirm your state's currently adopted edition before you study off a new code book.

**What's the most commonly missed question type?**
Calculation questions under time pressure, based on how consistently that pattern shows up across state pass-rate discussions and instructor feedback. Knowing the math isn't the same as executing it fast enough to finish the section.

**Can I skip a question and come back to it?**
Most PSI-delivered exams let you flag a question and return to it later within the same portion, as long as your time for that portion hasn't run out. Check your specific state's candidate bulletin, since this detail is set by the testing vendor's software configuration for that program.
